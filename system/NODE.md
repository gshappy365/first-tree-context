# System

This domain covers durable technical decisions and constraints for the Skills123 catalogue, its content model, and its delivery boundary.

## Leaves

- [Catalogue](catalogue/NODE.md) — how the catalogue represents, organizes, discovers, and presents skill packages and skill entries.
- [Content](content/NODE.md) — how topical knowledge bases, task scenarios, shared skill details, and upstream snapshots are bounded.
- [Delivery](delivery/NODE.md) — how the static site is published and how its delivery constraints are maintained.
